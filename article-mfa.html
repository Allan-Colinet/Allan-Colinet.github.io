Le MFA : Pourquoi c'est l'étape n°1 de votre sécurité

Si vous pensez que votre entreprise est en sécurité parce que vos collaborateurs utilisent des mots de passe complexes, une mise à jour s'impose. Face à l'industrialisation des cyberattaques, le mot de passe ne suffit plus. Il vous faut un verrou supplémentaire : le MFA (Authentification Multifactorielle).

L'équivalent numérique de votre carte bancaire

Pour retirer de l'argent, vous avez besoin de deux choses : votre carte physique (quelque chose que vous possédez) et votre code PIN (quelque chose que vous connaissez). Pour vos accès professionnels, c'est la même logique. Le système vous demande :

  • Un facteur de connaissance : Votre mot de passe.
  • Un facteur de possession : Une validation via une application sur votre smartphone.

Même si un attaquant vole votre mot de passe, il restera bloqué car il n'a pas votre téléphone entre les mains.

Quelles applications utiliser ?

La méthode la plus sûre est d'utiliser une application d'authentification installée sur votre smartphone. Voici les trois références du marché :

Microsoft Authenticator

Le standard si votre entreprise utilise Microsoft 365. Très confortable grâce à ses notifications : vous recevez une pop-up vous demandant "Approuver la connexion ?" sur votre téléphone.

Site officiel →

Google Authenticator

L'application historique, parfaite si vous travaillez sur Google Workspace. Elle génère un code à 6 chiffres qui change toutes les 30 secondes. Elle permet désormais la sauvegarde de vos codes dans votre compte Google.

Site officiel →

Twilio Authy

Une excellente alternative indépendante. Son grand avantage est la sauvegarde Cloud cryptée par défaut. Si vous perdez votre téléphone ou changez d'appareil, vous récupérez facilement tous vos accès sécurisés.

Site officiel →

Conclusion

Activer le MFA sur vos accès (boîte e-mail, réseaux sociaux professionnels, outils de facturation) est de votre responsabilité pour garantir l'étanchéité de votre entreprise. Prenez le temps de l'activer sur vos comptes vitaux, le risque d'intrusion s'en trouvera réduit de plus de 99%.
